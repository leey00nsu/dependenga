## 목적

- 랜딩 페이지의 중앙 비주얼이 비어 있어 브랜드 인상이 약함
- 분석 중 로딩 애니메이션이 테마와 어울리지 않아 몰입감을 해침
- 동일한 비주얼 언어(큐브 모티프)를 사용해 일관된 인상을 제공

---

## 사용자 스토리

### US-1: 랜딩 메인 비주얼 제공

**As a** 첫 방문 사용자  
**I want** 랜딩 중앙 영역에 큐브 기반 메인 비주얼을 보고  
**So that** 제품 콘셉트를 직관적으로 이해할 수 있다

**Acceptance Criteria:**
- [ ] 중앙 비주얼이 3x3x3 형태의 작은 큐브 모듈로 구성된다
- [ ] 붉은/주황/초록 계열 톤과 은은한 글로우가 적용된다
- [ ] 기존 레이아웃의 중앙 빈 영역을 대체한다

### US-2: 분석 로딩 애니메이션 테마 정합성

**As a** 분석을 실행한 사용자  
**I want** 로딩 애니메이션이 다크 테마와 큐브 모티프에 맞게 보이길  
**So that** 분석 흐름이 자연스럽고 일관되게 느껴진다

**Acceptance Criteria:**
- [ ] 분석 로딩 중 큐브 모티프 기반 애니메이션이 표시된다
- [ ] 밝은 플래시 없이 다크 톤으로 유지된다
- [ ] 큐브 형태/색감은 `docs/designs/cube.html`의 모티프를 따른다

---

## 기능 요구사항

### FR-1: 랜딩 메인 비주얼(3x3x3 큐브)

- 중앙 메인 영역에 3x3x3 작은 큐브가 모여 하나의 큐브를 이루는 비주얼을 배치한다
- 아이소메트릭 느낌과 공간감(간격 포함)을 유지한다
- 붉은/주황/초록 계열 컬러(#f87171, #fb923c, #4ade80)와 글로우 효과를 포함한다
- 상세 형태/레이아웃은 `docs/designs/cube.html`을 기준으로 한다
- 현재 랜딩 중앙의 플레이스홀더 영역을 대체한다

### FR-2: 분석 로딩 애니메이션 정리

- 분석 진행 중 로딩 화면에 큐브 모티프 기반 애니메이션을 표시한다
- 배경/텍스트 톤이 랜딩 및 결과 화면의 다크 테마와 일치한다
- 큐브 모티프는 `docs/designs/cube.html`의 구성 요소를 활용한다

---

## 비기능 요구사항

- **성능**: 로딩 중에도 프레임 드랍이 체감되지 않는다
- **보안**: 해당 없음
- **접근성**: 시각 요소는 대체 텍스트 또는 스크린리더용 라벨 제공

---

## 화면/플로우

- 랜딩 화면 중앙: 3x3x3 큐브 비주얼 (`docs/designs/cube.html` 기준, 중앙 플레이스홀더 대체)
- 분석 시작 후: 로딩 애니메이션 화면 (큐브 모티프, `docs/designs/cube.html` 기반)
