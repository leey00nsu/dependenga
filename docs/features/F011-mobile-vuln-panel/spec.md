## 목적

모바일 환경에서 결과 페이지의 취약점 리스트가 젠가 시각화를 가리는 문제를 해결한다. 사용자가 필요할 때만 리스트를 펼쳐 확인할 수 있도록 하여 시각화와 정보 접근성을 모두 확보한다.

---

## 사용자 스토리

### US-1: 모바일에서 리스트 접기

**As a** 모바일 사용자  
**I want** 취약점 리스트를 접고 필요할 때만 펼칠 수 있도록  
**So that** 젠가 시각화를 가리지 않고 결과를 확인할 수 있다

**Acceptance Criteria:**
- [ ] 모바일 뷰포트에서 취약점 패널이 기본적으로 접힌 상태로 표시된다
- [ ] 토글 동작으로 패널을 열고 닫을 수 있다

### US-2: 데스크톱에서도 접기 제공

**As a** 데스크톱 사용자  
**I want** 패널을 접을 수 있지만 기본은 펼쳐진 상태로 제공되도록  
**So that** 화면 레이아웃은 유지하면서 필요 시 화면을 더 넓게 사용할 수 있다

**Acceptance Criteria:**
- [ ] 데스크톱 뷰포트에서는 기본적으로 펼쳐진 상태로 표시된다
- [ ] 데스크톱에서도 토글로 접기/펼치기가 가능하다

---

## 기능 요구사항

### FR-1: 패널 접기/펼치기 토글 제공

모바일 뷰포트에서 취약점 패널을 접거나 펼칠 수 있는 토글 UI를 제공한다.

### FR-2: 모바일 기본 접힘

모바일 환경에서는 초기 진입 시 패널이 접힌 상태로 시작한다.

### FR-3: 접힘 상태 시 젠가 가림 최소화

접힘 상태에서는 젠가 시각화가 가려지지 않도록 패널이 최소 영역만 차지한다.

### FR-4: 데스크톱 토글 허용

데스크톱에서도 패널을 접고 펼칠 수 있어야 하며 기본값은 펼침 상태로 시작한다.

### FR-5: 데스크톱 캔버스 클립 완화

데스크톱에서 패널을 접었을 때 젠가 캔버스 영역이 확장되어 잘림이 완화되어야 한다.

### FR-6: 접근성

토글 UI는 키보드/스크린리더 접근이 가능해야 한다.

---

## 비기능 요구사항

- **성능**: 접기/펼치기 전환이 사용자 체감 지연 없이 동작한다
- **보안**: 해당 없음
- **접근성**: 토글 버튼에 명확한 레이블/상태(열림/닫힘)가 제공된다

---

## 화면/플로우

- 모바일: 결과 화면 진입 → 패널 기본 접힘 → 토글로 패널 열기/닫기
- 데스크톱: 기본 펼침 → 토글로 접기/펼치기 → 접힘 시 캔버스 영역 확장

---

## 엣지 케이스

- 취약점이 0개인 경우에도 토글이 동작해야 한다
- 화면 회전(가로/세로) 시 접힘 상태가 의도치 않게 변경되지 않도록 처리한다

- 취약점 리스트 UI 전면 재디자인
- 사용자 설정(로컬 저장) 기능
