## 상세 구현 단계

### 1) 결과 화면 레이아웃 재구성
- `HomeView`의 result state를 시안 구조로 재배치
- 배경/그리드/톤을 dashboard.png 기준으로 설정

### 2) 우측 패널(UI) 재디자인
- 취약점 요약 카드 + 패키지 리스트를 시안 스타일로 변경
- 배지/프로그레스/상태 색상 스타일 적용
- 상위 1개 취약점 제목/링크 노출

### 3) 비주얼 디테일 반영
- 색상/타이포/카드/배경 톤 정리
- 젠가 3D 영역 여백/정렬 조정

### 4) 반응형 동작 정의
- 주요 브레이크포인트에서 섹션 재배치
- 텍스트 오버플로/긴 숫자 표시 대응
