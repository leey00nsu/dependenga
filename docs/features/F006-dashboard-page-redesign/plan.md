## 아키텍처

대시보드 전용 뷰를 추가하고, UI 구성 요소를 시안 기준으로 재구성한다.

```text
[Dashboard Route] -> [DashboardView] -> [UI Sections]
```

## 파일 구조

```text
src/
├── app/
│   └── dashboard/
│       └── page.tsx               # 대시보드 라우트
├── views/
│   └── dashboard-view.tsx         # 대시보드 레이아웃
├── widgets/
│   └── dashboard/                 # (신규) 대시보드 섹션 컴포넌트
└── shared/
    └── ui/                         # 기존 컴포넌트 재사용
```

## 상세 구현 단계

### 1) 대시보드 라우트/뷰 구성
- `/dashboard` 라우트 생성 및 `DashboardView` 연결
- 레이아웃/그리드/섹션 구조를 시안 기준으로 설정

### 2) 섹션 컴포넌트 구성
- KPI/요약 카드, 리스트, 차트 영역 등 시안 기반 UI 구성
- 공통 UI 컴포넌트 재사용, 필요 시 신규 컴포넌트 추가

### 3) 스타일/비주얼 반영
- 색상/타이포/배지/버튼 등 디자인 톤 맞춤
- 배경 패턴/구분선/카드 스타일 조정

### 4) 반응형 동작 정의
- 주요 브레이크포인트에서 섹션 재배치
- 텍스트 오버플로/긴 숫자 표시 대응
