## 목적

`docs/designs/dashboard.png` 시안을 기준으로 대시보드 UI를 재구성하여
정보 구조와 시각적 일관성을 개선한다.

---

## 사용자 스토리

### US-1: 대시보드에서 핵심 정보를 직관적으로 확인

**As a** 사용자  
**I want** 디자인 시안과 동일한 레이아웃의 대시보드를 보고  
**So that** 주요 정보와 CTA를 빠르게 파악할 수 있다

**Acceptance Criteria:**
- [ ] 섹션 구성/순서/레이아웃이 `dashboard.png`와 일치한다
- [ ] 색상/타이포/컴포넌트 스타일이 시안과 일치한다

### US-2: 다양한 화면 크기에서 안정적인 대시보드

**As a** 사용자  
**I want** 화면 크기에 따라 레이아웃이 자연스럽게 조정되어  
**So that** 정보 탐색이 끊기지 않는다

**Acceptance Criteria:**
- [ ] 주요 섹션이 브레이크포인트별로 안정적으로 재배치된다
- [ ] 텍스트/컴포넌트 가독성이 유지된다

---

## 기능 요구사항

### FR-1: 레이아웃/구성 반영

`docs/designs/dashboard.png` 기준으로 섹션 구성, 그리드, 여백, 정렬을 반영한다.

### FR-2: 비주얼 스타일 반영

색상, 타이포그래피, 카드/버튼/배지 스타일을 시안과 동일하게 적용한다.

### FR-3: 에셋 적용 및 최적화

디자인에 포함된 이미지/아이콘을 적용하고, 웹 최적화(사이즈/포맷)를 유지한다.

### FR-4: 반응형 동작 정의

주요 브레이크포인트에서 섹션 정렬/스택/간격을 정의하여 시안 의도를 유지한다.

---

## 비기능 요구사항

- **성능**: 대시보드 로딩 성능을 기존 대비 악화시키지 않는다
- **보안**: UI 변경 중심 (인증/권한/데이터 로직 변경 없음)
- **접근성**: 색 대비, 시맨틱 태그, 포커스 상태를 유지한다
