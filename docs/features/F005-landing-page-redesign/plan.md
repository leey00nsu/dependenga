## 아키텍처

랜딩 상태의 UI를 디자인 시안에 맞게 재구성하고, 입력 로직은 기존 파서를 재사용한다.

```
[Landing UI] -> [DependencyParserForm] -> [parsePackageJson] -> [상태 전환]
```

## 상세 구현 단계

### 1) 랜딩 레이아웃 재구성
- `HomeView`의 initial state 레이아웃을 시안 구조(로고/중앙 비주얼/입력)로 재배치
- 배경: 다크 톤 + 그리드 라인 + 중앙 글로우 처리

### 2) 랜딩 입력 UI 반영
- `DependencyParserForm`에 랜딩 전용 변형(컴팩트 모드) 추가
- 디자인 시안의 검색 입력 + CTA 버튼 스타일 맞춤
- 기존 탭(직접 입력/URL) UI는 유지하고 스타일만 landing.png 기준으로 조정
- package.json 드래그 앤 드롭 업로드 지원

### 3) 헤더/버튼 스타일 반영
- 상단 좌측 로고 스타일링
- 로그인 버튼은 이번 범위에서 제외

### 4) 반응형 레이아웃 정리
- 모바일에서 헤더/비주얼/입력 스택 순서 고정
- 버튼/입력 크기, 텍스트 크기, 여백 조정

## 테스트 전략

- **수동 테스트**
  - 데스크탑: `landing.png`와 레이아웃/스타일 시각 비교
  - 모바일: 입력/버튼 가독성, 스크롤 흐름 확인
  - 기능: 입력 후 분석 정상 동작 확인
