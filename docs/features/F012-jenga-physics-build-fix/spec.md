## 목적

빌드 과정에서 발생하는 젠가 물리 관련 타입 오류를 해결해 배포/CI가 중단되지 않도록 한다.

---

## 사용자 스토리

### US-1: 빌드 오류 해소

**As a** 개발자/운영자  
**I want** 젠가 물리 로직이 빌드에서 타입 오류 없이 컴파일되도록  
**So that** 배포와 CI가 안정적으로 진행된다

**Acceptance Criteria:**
- [ ] Next.js 빌드가 타입 오류 없이 통과한다
- [ ] 젠가 물리 애니메이션의 동작/출력은 기존과 동일하다

---

## 기능 요구사항

### FR-1: 물리 임펄스 타입 오류 수정

`jenga-tower.tsx`의 물리 임펄스 적용이 올바른 타입을 사용하도록 수정한다.

### FR-2: 기존 동작 유지

렌더링/물리 시뮬레이션의 동작 결과는 변경하지 않는다.
