---

## 목적

사이트의 기본 메타데이터와 파비콘을 설정해 브라우저/공유 미리보기에서 일관된 브랜드 정보를 제공한다.

---

## 사용자 스토리

### US-1: 파비콘 적용

**As a** 방문자  
**I want** 탭/북마크에서 파비콘이 표시되도록  
**So that** 사이트를 쉽게 식별할 수 있다

**Acceptance Criteria:**
- [ ] 브라우저 탭에서 파비콘이 표시된다
- [ ] 기본 아이콘이 없을 때 깨진 아이콘이 보이지 않는다

### US-2: 기본 메타데이터 제공

**As a** 공유/검색 사용자  
**I want** 페이지 메타데이터가 설정되도록  
**So that** 공유 미리보기와 검색 결과에서 정보가 정확히 표시된다

**Acceptance Criteria:**
- [ ] 기본 title/description이 설정된다
- [ ] Open Graph/Twitter 카드 메타가 적용된다

---

## 기능 요구사항

### FR-1: 파비콘/앱 아이콘 설정

Next.js 메타데이터에 파비콘 및 기본 아이콘을 등록한다.

### FR-2: 기본 SEO/소셜 메타데이터 설정

title/description, Open Graph, Twitter 카드, theme-color를 설정한다.

- **보안**: 해당 없음
- **접근성**: 아이콘 대체 텍스트 제공 (필요 시)
